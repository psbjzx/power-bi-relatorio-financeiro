# Relatório Financeiro com Power BI

Projeto desenvolvido para um desafio da DIO, utilizando a base
Financial Sample para analisar vendas e lucro por produto,
segmento, país e período.

## Objetivo

Organizar os dados em um relatório interativo que facilite a
comparação de resultados e a identificação de padrões de vendas
e rentabilidade.

## Páginas do relatório

- **Vendas por produto:** vendas por produto, preço médio de venda
  e vendas por período e segmento.
- **Vendas e lucro:** total de vendas, unidades vendidas,
  lucro por país, lucro por período e vendas por país.
- **Análise geográfica:** distribuição de vendas e lucro por país
  e lucro por segmento.

## Ferramentas

- Power BI Desktop
- Microsoft Excel
- DAX

## Arquivos

- `dio.pbix`: projeto do Power BI.
- `Financial Sample.xlsx`: base de dados utilizada.
- `imagens/`: capturas das páginas do relatório.

## Como abrir

1. Baixe o arquivo `dio.pbix`.
2. Abra o projeto no Power BI Desktop.
3. Para atualizar os dados, ajuste o caminho da fonte do Excel
   para o local em que salvou `Financial Sample.xlsx`.
